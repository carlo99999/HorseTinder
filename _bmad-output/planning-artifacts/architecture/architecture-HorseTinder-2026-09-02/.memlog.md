- (direction) User selected Fast path and requested both a build-focused architecture spine and a short human-friendly explainer.
- (decision) Adopt a modular monolith: React SPA and Litestar API are independently deployable units communicating over versioned JSON HTTP; this prevents feature code from coupling across runtime boundaries.
- (decision) Use PostgreSQL as the sole system of record and server-authorized mutation endpoints; this prevents client-owned Match, Chat, Strike, and block state.
- (decision) Use REST JSON under /api/v1 and short-interval polling for Chat in v1; this prevents transport-specific real-time coupling before scale requires it.
- (decision) Use cookie-backed authenticated sessions with server-side ownership checks; this prevents exposing Match/Chat data through client-only routing.
- (version) Web-verified seed versions: React 19.2, Litestar 2.24, Vite 8.1 line, PostgreSQL 18 current.
- (event) Reviewer gate fixes applied: atomic social mutations, server-side block enforcement, idempotent ordered chat, deterministic fixtures, same-origin deployment with CSRF protection, and Vite updated to 8.2.
